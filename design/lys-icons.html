Aletheia Lys · icon set · v0.1

Ikon.

Forty-two icons for everything Aletheia holds: what a reading is, what an instructor can assign, how a course is built, and what you get out of it. One weight, one grid, no fills.

Rules

Drawn like type

The icons use the same line weight as the hairlines and the same ink as the text, so they read as part of the typography. Each one draws the thing itself (a book is a book, an outcome is a target) with as few strokes as it takes.

  • 24 px grid

    2 px of padding inside the box, so artwork lives in a 20 px area. Sizes are 16, 20, 24 and 32 only.

  • 1.5 px line

    One stroke weight at every size. Square caps and mitered corners, to match the cut edges of the layout.

  • Ink, never fill

    Icons take the text color. Cobalt appears on hover and focus only, so blue keeps meaning "you can act."

  • A label nearby

    Icons sit beside a word or carry an aria-label. They never stand in for the word on their own.

Construction

Same box, every icon

Shapes are built from straight lines, right angles and a few circles. The only curves are in the quote marks, the sample-course arc, the grading contract's signature, and the reader's open book.

  • Box24 × 24, artwork inside the 2 px keyline.
  • Stroke1.5, currentColor, square caps, miter joins.
  • DotsA zero-length line with square caps, so a dot is a 1.5 px square like everything else.
  • ReuseThe four license glyphs use the one filled shape in the set, because fill is what they communicate.

Use

In the codebase

One sprite file and one small component. The sprite ships as design/lys-icons.svg and every icon is a <use> reference, so the stroke follows the surrounding text color in both themes.

Componentfrontend/src/components/Icon.tsx

export function Icon({ name, size = 24, label }: { name: string; size?: 16 | 20 | 24 | 32; label?: string }) { return ( <svg width={size} height={size} role={label ? "img" : undefined} aria-label={label} aria-hidden={label ? undefined : true} className="ic"> <use href={`/icons.svg#i-${name}`} /> </svg> ); }

Avoid

  • 1.5 px only

    Don't change the line weight to make an icon heavier or lighter. Change the size step instead.

  • Don't color an icon blue at rest. Blue is for hover, focus, and the one action on the page.

  • Don't scale between steps. Stay on 16, 20, 24 or 32.

Two calls to check. The primary text icon is a pair of quote marks, and journal is two offset pages. If either reads wrong at 16 px in testing, swap it before the set is locked.
