## Approving

From the repository root, with the backend virtualenv's Python:

```
python tools/harvest/merge.py --approve all --queue research/harvest/queue-20261017.jsonl --dry-run
python tools/harvest/merge.py --approve <book-id>,<book-id> --queue research/harvest/queue-20261017.jsonl
cd backend && python manage.py load_pack rhetcomp
```

`all` takes every record marked new; near duplicates must be named by id. A book id brings its chapters (add `--book-only` to skip them).
